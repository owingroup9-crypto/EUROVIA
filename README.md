# Website EUROVIA

Website tĩnh (HTML/CSS/JS thuần) của Công ty Cổ phần Tập đoàn EUROVIA – https://eurovia.com.vn

- `index.html`: toàn bộ trang. Thông tin công ty (hotline, email, địa chỉ, Zalo…) sửa ở khối `CONFIG` đầu thẻ `<script>`.
- `assets/img/`: hình ảnh.

Không cần build: chỉ cần đưa thư mục này lên hosting, trang chủ là `index.html`.
